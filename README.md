# 门店日报

给营业厅用的日报：只填当天数字，本月累计自动算，一键复制微信群播报，同时留下日报 / 周报 / 月报。

个人微信群没有官方机器人，所以现在是 **保存 → 复制 → 贴群**。数据按多店、多人建好了，以后加店、换人不用推倒。

和投资账本 `invest-tracker` 分开，互不影响。局域网 VPS（`192.168.100.5`）步骤见 [docs/deploy-vps.md](docs/deploy-vps.md)。

## 现在怎么用

```bash
cd /Users/jian/Downloads/store-daily
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python wsgi.py
```

浏览器打开 http://127.0.0.1:5055

| 账号 | 口令 | 角色 |
|---|---|---|
| `admin` | `1234` | 管理员，能加店、加人、改月目标 |
| 各店账号 | `123456` | 11 家店各一个填报员，账号不超过 8 位，见设置 → 人员 |

登录后请立刻在「设置」里改口令。

当天流程：

1. 打开「今日填报」，只改「日」那一列
2. 点「保存并重算累计」
3. 点「复制全文」，贴进微信群

数字化一长串全 0 可以勾「日=0 且累=0 的行不进群消息」。

预置 11 家南通 TZ 店（海门金花、启东人民中路、通州金沙、通州万达、海安人民中路、海安万达、如皋宁海路、大有镜、港闸万达、开发区、崇川长桥）。管理员看全部；`ninghai` 只看宁海路。店名改 `app/stores_seed.py` 即可，启动会按官方名对齐，已有日报不会丢。

## 页面

- **今日填报**：按你现在的群格式分组，右侧实时显示本月累计
- **报表**：日报 / 周报 / 月报，可导出 CSV
- **通报表**：11 家店一行一张，版式对齐现有 Excel/微信通报（档案 + 跟进 + 月累 + 当日）
- **多店看板**：看各店交了没有、重点业务日/累
- **设置**（管理员）：加店、加人、改门店档案、分配可填门店、改月目标

## 口径

- 只存「日」。累 = 本月 1 号到所选日期的日合计
- 每月 1 号自动从 0 开始，不用手清
- 同一店同一天可覆盖保存，留下最后提交人和时间
- 填报员只能看到被分配的店；管理员看全部

## 以后多店多人

1. 设置 → 加门店（店名 + 编码，如 `rg-xxx`）
2. 设置 → 加人员，勾选他能填的店
3. 店员用自己的账号登录，下拉框里只有自己的店
4. 管理员看「多店看板」盯有没有漏交

还是个人微信的话，各店各自复制进自己的群。如果以后群改成企业微信，再加群机器人 webhook 就能自动发，表单不用改。

## 同步到 VPS

这台 VPS 是局域网 `192.168.100.5`，Caddy 绑 `0.0.0.0:8099`（8088 已有其他服务，不抢），不要用 127.0.0.1。

```bash
cd /Users/jian/Downloads/store-daily
./scripts/sync_to_vps.sh
```

同一 Wi‑Fi / 内网打开 http://192.168.100.5:8099  。详见 [docs/deploy-vps.md](docs/deploy-vps.md)。

## 数据

默认库在 `data/store_daily.db`。换路径：

```bash
export STORE_DAILY_DB=/path/to/store_daily.db
export STORE_DAILY_SECRET='换成一段随机字符串'
```
